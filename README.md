# LiveGeometry
Interactive geometry CAD-like educational software.

https://livegeometry.com

Create interactive ruler and compass constructions and experiment with them.

The core engine is a flexible and extensible framework that allows you to easily add new figure types and features. The project has many front-ends, the most modern one using Avalonia.

![screenshot](/docs/screenshot.png)

## Sharing your drawings

Use the Export button:
 * Save as .lgf
 * Save as .png
 * Save as .svg
 * Save as .html
 * Copy share link
 * Copy image
 * Copy embed code

## Embedding your drawings

See https://livegeometry.com/embed on how to embed drawings into your own web pages, blog posts, teaching materials etc.
